# 数読の祝詞

数読の祝詞は、算へのことを祝詞・宣命のことばにて書き、からくりに読ませ行はしむる言なり。
この処理系 `noritoc` は、源文 `.nrt` を言割り、文組みし、木を成して、ただちに算ひ行ふ。
また木を見むと欲らば `--kaiseki` を用ゐ、椎言語に写さむと欲らば `--backend=c` を用ゐよ。

## 作り方

この処理系は椎十一にて作れり。外の庫を頼まず、標準の庫のみを用ゐる。

```sh
make
```

清めてまた作らむには、かくすべし。

```sh
make clean
make
```

## 行はせ方

源文を実行せむには、かくすべし。

```sh
./noritoc test/fizzbuzz.nrt
```

木のかたちを見むには、かくすべし。

```sh
./noritoc test/fizzbuzz.nrt --kaiseki
```

椎言語に写さむには、かくすべし。

```sh
./noritoc test/fizzbuzz.nrt --backend=c
```

## 仮名の厳しきさま

常には今のかなを許す。

```sh
./noritoc source.nrt --kana=modern
```

甲乙をたださむには、特殊のかなの後に `甲` または `乙` を置きて書け。
文字列、注、読みを示す括弧の内はこの責めを受けず。

```sh
./noritoc source.nrt --kana=ko-otsu
```

万葉仮名にて厳しく書かむには、コードのところにかなを直に書くことを許さず。
処理系は定めたる万葉仮名の表により、今のかなへ正してのち読む。

```sh
./noritoc source.nrt --kana=manyogana
```

## 試み

試みをみな行はせむには、かくすべし。

```sh
make test
```

この試みは、源文の実行、木を見ること、過ちの報せ、八位うつし字の検め、甲乙・万葉仮名の厳しきさま、
また写したる椎言語を作り行はせて同じ出力を得ることを検む。

## 例

```nrt
階とふ業は、ぬを賜はりて、
　一を みに置く。
　一よりぬに至るまで数ふるごとに、みを その数に掛けたるを みに置く。
　みを返す。
と宣る。

五の階を告る。
```

これを行はせば、かく出づ。

```text
120
```

## 過ち

源文に過ちあらば、処理系は行・列を添へて `過ち有り` と告ぐ。
未だ定めぬ名、零にて割ること、閉ぢぬ文、空しき本体、正しからぬ八位うつし字などは、
隠さずただちに報す。

## 免し

この蔵は、数読の祝詞の処理系を作り、試み、改めむ人のために置けり。
用ゐむ人は作り文と試みの源文を見て、その道を知るべし。
